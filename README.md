USB-Sandbox VM Download
=======================

The preconfigured USB-Sandbox virtual machine is too large to store directly in this GitHub repository.

Download it here:

https://drive.google.com/file/d/1AUgf5q3lq8nT5e0Iw7gim54GjZYs299U/view?usp=sharing

After downloading the file:

1. Install VirtualBox.
2. Import the USB-Sandbox appliance.
3. Make sure the imported VM is named exactly:

USB-Sandbox

No additional configuration inside the VM is required.
